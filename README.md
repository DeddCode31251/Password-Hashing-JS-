# Password-Hashing-JS-
The simplest password hashing program using Javascript made by Deadcode

## File Structure

/folder/main.js

## Libraries
- **Crypto**

## How this App Works
- 1- Importing crypto librarie
- 2- Making a function to hash passwords **hashPassword()**
- 3- in **hashPassword()** first add the 16 bytes salt then hash using scryptSync
- 4- make a verify password function **verifyPassword()**
- 5- Using Args to get user input password1 password2 to test
- 6- All Function work together to get the results
